# Touseef Panjtan - Modern Developer Portfolio 2.0 🚀

A high-performance, sleek, and professional developer portfolio built to showcase technical expertise and projects. Designed with a focus on modern UI/UX principles, smooth interactions, and a "premium" dark aesthetic.

## 🌟 Features

- **Modern Tech Stack**: Built using **React 19**, **TypeScript**, and **Tailwind CSS**.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Interactive UI**:
  - **Reveal-on-Scroll**: Sections fade and slide into view as you scroll.
  - **Dynamic Skills Bar**: Animated percentage counters and shimmering progress bars.
  - **Project Hover Effects**: High-intensity orange glow and lift effects for project cards.
  - **Testimonial Slider**: Auto-playing slider for client feedback.
- **Smooth Navigation**: One-page layout with active section highlighting in the navbar.
- **Professional Integration**: 
  - Direct links to **GitHub** and **LinkedIn**.
  - Visual 'Download CV' button.
  - Functional contact form interface with submission status.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) (Version 19)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: Custom CSS Animations & Intersection Observer API
